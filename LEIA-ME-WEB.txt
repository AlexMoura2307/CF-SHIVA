CF SHIVA V3 — versão WEB para Render

1. Suba esta pasta em um repositório GitHub.
2. No Render, crie um Web Service apontando para o repositório.
3. O render.yaml já informa:
   Build: pip install -r requirements.txt
   Start: gunicorn app:app
4. Abra a URL gerada pelo Render.

Observação:
A interface web e a estrutura de processamento em lote estão prontas.
A automação real de consulta/download no SHIVA depende dos seletores,
credenciais e ambiente do portal. O código desktop original foi preservado
em CF_SHIVA_original.py para referência durante a integração.
